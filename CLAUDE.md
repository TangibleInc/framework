# Notes for agents

## Strings

Read `../tangible-strings/STYLE-GUIDE.md` before you add or change a user-facing string. It comes from [TangibleInc/tangible-strings](https://github.com/TangibleInc/tangible-strings), checked out beside this repo.

Run `npm run i18n:lint` before you commit. It fails on a wrong or missing text domain, a placeholder with no `translators:` comment, or a British spelling.
